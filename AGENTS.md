# AGENTS.md

## What this repo is

A self-contained Open Data Cube (ODC) environment for the Indonesia Data Cube (INADC): PostGIS + ODC running under Docker Compose. There is no root-level Python package — the repo is the ODC Docker image, product definitions, custom metadata types, and Makefile automation.

It is also the source of truth for the ODC `products/` definitions, `products.csv`, and `metadata/` types that the cluster's Argo/Kubernetes workflows consume via raw GitHub URLs.

## Setup (required before anything works)

```bash
make setup    # creates .env from .env.example, generates datacube.conf
make build    # builds the ODC Docker image
make up       # starts PostgreSQL + ODC containers
make init-db  # initialises the ODC database schema (run once after first `up`)
```

## Key paths

- `docker-compose.yml` — compose file (repo root); services `postgres` + `odc`
- `Dockerfile` — ODC image; uses `uv` with `pyproject.toml` (pinned `datacube==1.9.18`)
- `pyproject.toml` / `uv.lock` — ODC Python dependencies
- `entrypoint.sh` — ODC container entrypoint
- `products/*.yaml` — ODC product definitions, mounted into the container at `/home/venv/products/`
- `products.csv` — product catalogue consumed by the cluster sync workflow
- `metadata/custom_metadata.odc-type.yaml` — custom ODC metadata type
- `scripts/generate_config.sh` — runs `envsubst` on `datacube.conf.template`
- `datacube.conf` — generated, gitignored; template is `datacube.conf.template`

## Testing

Lightweight unit tests only (no Docker required). A host `.venv` runs pytest.

```bash
make test-deps     # creates .venv, installs pytest + deps (run first)
make test-unit     # runs unit tests
make test          # alias for test-unit
make test-verbose  # unit tests with -xvs
make test-clean    # removes .venv, caches, coverage
```

Unit tests validate product definitions and config (`tests/unit/`). `test_configs.py` needs `datacube.conf`, so run `make setup` first (CI does this).

## Indexing

Per-product targets use short names: `index-s2l2a`, `index-s1rtc`, `index-ls9sr`/`index-ls8sr`/`index-ls7sr`/`index-ls5sr` (surface reflectance), `index-ls9st`/`index-ls8st`/`index-ls7st`/`index-ls5st` (surface temperature), `index-s2gm` / `index-s2gm120` (geomedian), `index-flood`. Aggregates: `index-landsat`, `index-gm`, `index-all`. STAC indexing takes `Bbox`, `Date` overrides; the stack must be running.

## Dependency management

Uses `uv` (astral) for the ODC lockfile:

```bash
make compile-deps  # compiles pyproject.toml -> uv.lock
make update-deps   # recompiles with --upgrade
```

## Common pitfalls

- **`.env` must exist** before `make up` or any compose command. Created by `make setup`.
- **`datacube.conf` is gitignored** — generated by `make setup` via `envsubst`. Edit `datacube.conf.template`, not the generated file.
- **Products must be added after init**: `make all-products` or `make add-product F=<file.yaml>`.
- **Indexing commands** run `stac-to-dc` / `s3-to-dc` inside the ODC container — the stack must be running.
- Docker platform is pinned to `linux/x86_64`; Python 3.12.

## CI (GitHub Actions)

- **Tests** (`.github/workflows/test-odc.yml`): on push to `main`/`develop`/`feature/*` and PRs to `main`/`develop`; runs `make setup`, `make test-deps`, `make test-unit`.
- **Image build** (`.github/workflows/build-inadc-odc.yml`): pushing a tag `inadc-odc-vYYYYMMDD-HHMM` builds and pushes the ODC image to the `inadc-odc` ECR repo.
